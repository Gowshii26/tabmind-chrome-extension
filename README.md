# TabMind – Smart Chrome Tab Manager

TabMind is a lightweight Chrome Extension designed to help users manage and organize browser tabs more efficiently. It analyzes open tabs and highlights important ones, helping reduce tab clutter and improve productivity.

---

## 🚀 Features

- Detects and lists all open browser tabs
- Categorizes tabs as **Important** or **Normal**
- Clean and simple **popup dashboard UI**
- Lightweight and fast Chrome extension
- Helps users stay organized while browsing

---

## 🛠 Tech Stack

- **JavaScript**
- **HTML**
- **CSS**
- **Chrome Extensions API**

## ⚙️ Installation (Developer Mode)

1. Download or clone this repository

2. Open **Google Chrome**

3. Go to chrome://extensions/
 
4. Enable **Developer Mode** (top right corner)

5. Click **Load Unpacked**

6. Select the **TabMind project folder**

7. The extension will appear in the Chrome toolbar
